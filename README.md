# 🐕 Canicross — Repositório de Desenvolvimento

Jogo de Canicross cinematográfico com estética low-poly. 
Unity 6 + URP + WebGL.

## Estrutura

```
cani-game/
├── GDD.md                  # Documento de design completo
├── Canicross/              # Projeto Unity
│   ├── Assets/_Game/       # Scripts, Shaders, Prefabs
│   └── Packages/           # URP + dependências
├── Characters/             # Modelagem 3D
│   ├── Adao_Dog/           # Cão Adão (Malinois) — @adao.superacao
│   └── Alexandre_Runner/   # Corredor Alexandre
└── Reference/              # Vídeos de referência baixados
    ├── canicross_video.mp4
    └── canicross_reel.mp4
```
