# 🐕 Adão — Cão (Malinois)

**Referência:** [@adao.superacao — Highlights "Canicross"](https://www.instagram.com/stories/highlights/18259015006201085/)

## Características Físicas
- **Raça:** Pastor Belga Malinois
- **Pelagem:** Curta, fulvo com máscara preta no focinho
- **Porte:** Médio-grande (~25-30 kg, ~60 cm na cernelha)
- **Estrutura:** Atlética, peito profundo, patas longas, cauda média

## Referências para Modelagem 3D

### Fotos de Referência (a baixar)
- [ ] Perfil lateral (standing) — proporções corpo inteiro
- [ ] Frontal — largura do peito, posição das patas
- [ ] Traseira — cauda, posteriores
- [ ] Close do focinho — máscara preta, orelhas eretas
- [ ] Em movimento (correndo) — pose dinâmica
- [ ] Close dos olhos — expressão

### Características para o Modelo Low-Poly
- **Tri count alvo:** ~1500-3000 tris (estilo low poly)
- **Cor base:** Fulvo/dourado `#D4A04A`
- **Máscara:** Preto `#1C1C1C`
- **Coleira:** Azul elétrico `#00BFFF` (corda do canicross)
- **Estilo:** Flat shading com ToonLit shader

### Animações Necessárias
- [ ] Idle (parado, respirando)
- [ ] Walk (caminhada)
- [ ] Run (corrida)
- [ ] Sprint/Gallop (velocidade máxima)
- [ ] Jump (salto sobre obstáculo)
- [ ] Look Back (olhar para trás — check-in)
- [ ] Bark (latir)
- [ ] Tail Wag (abanar rabo)
