# 🏃 Alexandre — Corredor

**Referência:** [@adao.superacao — Highlights "Canicross"](https://www.instagram.com/stories/highlights/18259015006201085/)

## Características Físicas
- **Tipo:** Corredor de canicross
- **Altura:** ~1.75m
- **Equipamento:** Cinto de canicross, roupa esportiva, tênis de trail
- **Postura:** Ligeiramente inclinado para frente ao correr

### Características para o Modelo Low-Poly
- **Tri count alvo:** ~2000-4000 tris
- **Estilo:** Flat shading low poly
- **Cores:** Roupa esportiva (cores vibrantes), tênis de trilha
- **Cinto:** Cinto de canicross com ponto de ancoragem
- **Corda:** Azul `#00BFFF` saindo do cinto até o cão

### Animações Necessárias
- [ ] Idle (parado, respirando, segurando a corda)
- [ ] Run (corrida normal)
- [ ] Sprint (corrida rápida, inclinado)
- [ ] Jump (salto sincronizado com o cão)
- [ ] Pull Back (frear/segurar)
- [ ] Look at Dog (olhar para o cão)

### Notas para o Rig
- O ponto de ancoragem da corda no cinto é crítico — a corda sai da cintura
- As mãos seguram a corda à frente do corpo
- O CharacterController do Unity vai gerenciar a física; o rig é para animação visual
